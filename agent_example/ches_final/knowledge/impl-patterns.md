# impl-patterns — RTL 安全缺陷模式库(审计扫描语言)

常见硬件安全缺陷形状目录。每模式:代码形状(auditor 扫描用)/ 验证方法
(poc-runner 断言设计用)/ 典型资产与 CVSS 方向(reporter 用)。全流水线
用同一套词。**模式只是扫描镜头,不是立项标准**——任何发现仍须当场写成
完整攻击叙事(七门),写不全=[minor] 不进链。

## 扫描总则(攻击者第一视角)
- 模式扫描 = 在对手可达面上找这些形状,不是全树无差别找茬
- 先回答「这个区域的保护声明了什么、交付引导流启用了什么」,再按模式
  对照实现
- 形状命中只是线索;越界成立与否=七门事实

## 模式目录

### clear-integrity(清除/净化路径弱化)
- 形状:*_clear / wipe / scrub / zeroize 信号的赋值源不是零/随机化值;
  清除条件被收窄(`if (!rst_ni)` 加额外与项,特定状态下不清)
- 扫描:找 clear/wipe/scrub/zeroize 信号的全部消费点,核对赋值源与
  条件宽度;比较复位分支敏感列表
- 验证:触发清除/复位后读寄存器,expected_secure=全零/新值,
  observed=残留旧值
- 资产:key/seed/state 寄存器残留;机密性方向,通常 High

### fsm-default(FSM default/非法态弱化)
- 形状:case 无 default 或 default 转 Stay/野态;unique 修饰缺失;
  状态编码可跳变到特权态;复位值落在特权态
- 扫描:全 FSM case 查 default 目标态;状态向量宽度与合法值集;
  复位值 vs 安全态
- 验证:非法 state 值注入,断言应进 error/terminal 态
- 资产:FSM 逃逸到特权态;完整性方向

### param-config(安全参数硬编码/默认翻转)
- 形状:Sec*/Lock*/Allow* 参数的消费点改读常量;参数默认值翻转;
  掩码/旁路使能固定;出厂参数关闭保护而无人再开
- 扫描:grep Sec*/Lock*/Allow* 参数定义与全部消费点,查消费点真用
  参数;hjson param/resval 出厂值
- 验证:-G 双参数天然适配(参数开/关两臂行为对比)
- 资产:对策被静默解除;视对策而定

### wipe-reachability(擦除/初始化逻辑不可达)
- 形状:init/wipe/erase 循环体条件恒假、计数器恒 0、触发源缺失
- 扫描:找 init/wipe/erase 相关 always 块与循环计数器,检查可达性
- 验证:触发擦除流程,断言存储体内容变化
- 资产:密钥材料/OTP 影子寄存器残留

### logic-inversion(布尔弱化/互换)
- 形状:`&&`↔`||` 互换、比较符翻转、取反增删,使安全检查恒真/恒假
- 扫描:对策使能信号的表达式逐项复核(尤其 lock/mask/regwen/perm 检查)
- 验证:构造检查应拦截的输入,断言拦截与否
- 资产:权限检查失效;完整性方向

### info-flow(秘密跨界)
- 形状:机密信号(密钥/种子/内部状态)进软件可观测通道(状态寄存器/
  调试总线/错误码/时序侧信道);常量折叠把秘密变可读
- 扫描:秘密信号的全部 fanout,追到架构可见观测点;错误通道携带
  秘密依赖信息
- 验证:固定数值锚点——读回值与秘密值建立可判定关系
- 资产:机密性方向

### countermeasure-wiring(反制连线悬空/门条件错)
- 形状:hjson SEC_CM 声明的 countermeasure 在 RTL 无对应实现或连线
  悬空;门条件写错(覆盖不全/被旁路);告警/状态位从不置位
- 扫描:声明保证清单→实现对照(SEC_CM 逐条追到 RTL 信号级:
  门在不在/门条件对不对/门覆盖全不全/被旁路的路径)
- 验证:构造应被拦截的攻击输入,断言告警/拦截行为
- 资产:视被绕过的对策而定

### lock-semantics(REGWEN/锁时序)
- 形状:锁写后仍可写(REGWEN 检查在写路径之外);锁清除路径未按
  锁定承诺门控;shadowed 寄存器窗口竞态;TOCTOU(检查与使用之间
  状态可变)
- 扫描:REGWEN 消费点与写使能的相对位置;commit/update 窗口
- 验证:上锁后写+读回,断言写被拒
- 资产:持久化越权(锁形同虚设)

### sync-reset(同步器与复位面)
- 形状:跨时钟域信号少同步级;异步复位释放无同步;复位毛刺下
  状态半清(部分寄存器清、部分不清);good/done 类跨域握手无毛刺
  防护
- 扫描:cdc 结构、复位树、握手协议
- 验证:注入单拍毛刺,断言状态机进入安全态
- 资产:状态机复活/提前放行;完整性方向
